# Curve War — 기획 문서 (초안 v0.1)

## 1. 한 줄 소개
영토 경계(전선)가 **곡선**으로 표현되고, 플레이어가 유닛이 아니라 **전선 곡선 자체를 조작**해 싸우는 일시정지 가능한 실시간 전쟁 전략 시뮬레이터.

## 2. 차별점
| 구분 | 문명류 / 일반 전쟁 전략 | Curve War |
|---|---|---|
| 공간 | 타일(격자/헥스) | 연속 2D 평면 |
| 영토 | 타일 소유권 | 닫힌 곡선(스플라인)의 내부 |
| 조작 | 유닛 개별 이동·명령 | 전선 제어점 이동 |
| 병력 | 유닛 수 | 전선 단위 길이당 **밀도** |
| 핵심 판단 | 무엇을 생산할까 | 전선 **모양**을 어떻게 만들까 |

## 3. 핵심 메커니즘

### 3.1 전선 곡선
- 각 세력의 영토는 닫힌 곡선(예: Catmull-Rom 또는 B-spline)으로 정의한다.
- 곡선은 N개의 제어점으로 구성되고, 플레이어는 제어점을 드래그하거나 구간을 선택해 "밀기/당기기"를 지시한다.
- 두 세력의 곡선이 만나는 구간이 **접촉 전선**이다.

### 3.2 병력 밀도와 압력
- 세력은 총병력 `T`를 가진다. 전선 길이를 `L`이라 하면 평균 밀도는 `d = T / L`.
- 접촉 전선의 각 지점에서 양측 밀도 차이가 **압력**이 되어 전선을 밀어낸다.
  - 압력이 센 쪽 곡선이 상대 쪽으로 전진한다.
- 결과:
  - 돌출부(salient)는 전진하기 좋지만 길이가 늘어 밀도가 떨어지고 측면 포위에 약하다.
  - 곧고 짧은 전선은 단단하지만 진격이 느리다.

### 3.3 보급과 포위
- 영토 내부에는 보급 원천(수도/보급소)이 있고, 보급은 영토 내부를 통해 퍼진다.
- 상대 곡선에 둘러싸여 보급원과 단절된 영역은 **고립**되며 시간이 지날수록 밀도가 감소한다.
- 곡선이 자기 자신과 교차하는 조작은 금지하거나 자동으로 보정한다(§7 미결).

### 3.4 지형 = 힘 필드
- 산: 곡선을 밀어내거나 전진 속도를 늦춘다.
- 강: 건널 때 밀도 페널티, 다리/여울에서만 낮음.
- 도로: 보급 전달과 전진 속도 증가.
- 지형은 타일이 아니라 연속 스칼라/벡터 필드(또는 폴리곤 영역)로 정의한다.

### 3.5 시간 진행
- 기본은 실시간으로 곡선이 진화한다.
- 일시정지 중에도 제어점 조작과 명령 예약이 가능하다. 재개하면 한꺼번에 적용된다.
- 속도 배율(×1, ×2, ×4) 제공.

## 4. 승리 조건 (초안)
- 상대 수도를 곡선 내부에 포함시키거나, 상대 영토 면적이 임계값 이하로 떨어지면 승리.

## 5. 기술 스택
- TypeScript + HTML Canvas 2D (빌드는 Vite 예정)
- 시뮬레이션 코어(순수 TS)와 렌더링을 분리해 코어를 단위 테스트할 수 있게 한다.
- 고정 시간 간격(fixed timestep) 시뮬레이션, 렌더링은 보간.

## 6. 마일스톤
1. **M0 프로젝트 뼈대**: Vite + TS, 캔버스 렌더, 게임 루프, 일시정지.
2. **M1 곡선 영토**: 두 세력의 닫힌 곡선 렌더링과 제어점 드래그.
3. **M2 압력 시뮬레이션**: 밀도/압력 계산, 접촉 전선 이동.
4. **M3 보급·포위**: 보급 전파, 고립 판정과 감쇠.
5. **M4 지형 필드**: 산/강/도로 도입.
6. **M5 AI 1종**: 단순 규칙 기반 상대.
7. **M6 승패·UI 다듬기**.

M2까지 만든 뒤 "재미가 있는지"를 먼저 판단하고 이후 범위를 조정한다.

## 7. 미결 사항 (논의 필요)
- 곡선 자기 교차를 막을지, 허용하고 영토 불리언 연산(폴리곤 클리핑)으로 처리할지
- 압력 → 전진 속도 변환 식과 수치 균형
- 다수 세력(3개 이상) 지원 시점
- 병종/특수 능력 도입 여부(도입한다면 "밀도"와 어떻게 결합할지)
- 멀티플레이 여부
