- 개간 레버는 시기를 고르는 투자 결정이지만 폭이 작다("늦게 하는 쪽이 거의 항상 낫다", `MODEL.md` 7절). 개간 노동량은 근거 없는 임시값이다.
- 개간 예측에 흉년 시나리오를 추가해 확인한 정보: 흉년에서는 이른 개간이 오히려 기아 사망을 늘린다(10년 뒤 1,635 → 1,896명). 평년 표만 보면 안 보이던 점이다. 이 변화는 검사 규칙 2번(두 시나리오)을 구현하면서 얻었다.

## 단계 0 (변수 감사) — 총평: 빈껍데기 1건 제거, 구조적 문제 여러 건 확인, 감사 도구 결함 2건 발견·수정. 절반만 끝남

자세한 내용은 `AUDIT.md`. 불합격·미흡만 요약한다.

- **감사 도구의 결함으로 처음 결과 일부가 틀렸다**: (1) 시작 데이터 패치가 전쟁에 안 쓰이는 `START_REGIONS`를 먼저 바꿔 곡창·경작지·지배층 제거가 "변화 없음"으로 잘못 나옴. (2) 평균만 비교해서 분산만 바꾸는 변수(전황 변수, 기상)를 "빈껍데기"로 오판할 뻔함. 둘 다 고쳐 다시 돌렸다. 같은 종류의 오판이 앞으로도 가능하다(정책이 쓰지 않는 기능, 문턱 설정).
- **개간 레버는 전쟁 게임에서 빈껍데기**였다 (방어+개간 vs 방어: 영토 +0.4%p, 인구 +35명, 수확 −200t). UI와 타이머에서 제거했다. 이 레버는 M1.5에서 "시기를 고르는 투자 결정"이라고 평가했지만 전쟁이 들어오자 의미를 잃었다. 이전 평가가 틀린 것은 아니고 전제가 바뀐 것이다.
- **장인·상인·지배층은 여전히 고유 역할이 없다**(단계 4로 미룸).
- **난이도가 한 숫자에 달린 절벽**: 적의 병력 따라가기 배율(0.5 ↔ 1.5)이 승패를 뒤집는다. 근본 해결은 단계 1.
- **곡식 수지가 비대칭 문턱 근처**: 근거 없는 임시 상수 몇 개가 기근 여부를 가른다. 상수 근거 조사가 더 필요하다.
- 합격: 읽는 곳 지도에서 죽은 상수 0개, 화면 전용 상수 0개, 감사 자동화(`npm run audit`).

### 검사에서 찾아 고친 것
- **전황 변수가 이동에는 적용되지 않던 버그**: 사상에만 곱해지고 전진 속도에는 빠져 있었다. 시드마다 결과가 거의 같던 이유였다. 고치면서 균형이 크게 바뀌어 다시 측정했다.
- 폰에서 헤더의 날짜가 한 글자씩 세로로 쪼개짐 → 좁은 폭에서는 헤더를 세로로 쌓도록 변경.
- 폰에서 계절 칸의 글자가 깨짐 → 좁은 폭에서는 일수 표기를 숨김.
- 폰에서 가장 중요한 "참모의 보고"가 지도 아래 한참 밑에 있었음 → 좁은 화면에서는 지도 바로 아래로 순서를 올림.
- 타이머 칸에서 "이번 계절"이 "이번 계 절"로 깨짐 → 칸 너비를 넓히고 줄바꿈 금지.
- 이번 계절 예상에서 영토를 1% 넘게 잃는데 참모가 경고하지 않음 → 예상 기반 경고/기회 추가.
- 폰에서 지도 위 훈련 라벨이 지도 밖으로 잘림 → 안쪽으로 당겨 그림.
- 범례의 "이번 달 예상 전선"이 낡은 문구로 남아 있었음 → 수정. 시작 안내의 "오른쪽 병력 패널"도 폰에서는 틀려 수정.
- 창 크기를 바꾸면 캔버스가 한 프레임 비던 문제 → 크기 변경 시 곧바로 그리도록 변경.
- 적 AI가 턴 경계와 맞지 않는 수확 철 창에 의존해 수확 때 병력을 못 줄이던 문제(턴 단위로 바꾸면서 발생) → "수확이 있는 턴"이라는 개념으로 교체.

### 이번에 검사로 찾아 고친 것
- 지도 위아래 여백이 없어 전선 양 끝 점이 반쯤 잘렸다 → 여백 추가.
- "다음 달" 버튼이 진행 중에도 눌린 상태로 보였다 → "진행 중…"으로 비활성화.
- 월간 보고가 "후퇴 0.7km"와 "마을 점령"을 함께 써서 모순돼 보였다 → 가장 크게 전진한 구간과 후퇴한 구간을 따로 적도록 변경.
- 적이 다음 달에 병력을 절반으로 줄이는데(수확 철) 참모가 알려주지 않았다 → 예측을 보고 "기회"를 알린다.
- 일손 여유가 0일 때 "-0명"으로 나왔다 → 수정.
- 전선 양 끝 점의 병력 밀도가 두 배로 계산되던 오류(점마다 병력을 균등 배분) → 전선 길이에 비례해 배분하도록 수정, 시험 추가.
- 한쪽이 자발적으로 물러나면 상대의 "현재 전선 유지" 명령이 그 땅을 도로 빼앗던 오류 → 자발적 후퇴는 플레이어만 하도록 수정.
- 명령선이 적 수도에 닿지 못하게 막혀 있어 승리가 불가능했던 오류 → 명령선 범위 확대.

## 폐기한 설계: 계층별 분배 · 공공 비축 · 구휼 (M2 후보였음)

계획했던 M2("계층별 소유, 세금·지대, 구휼")를 코드로 옮겨 측정했고, **같은 검사 기준으로 불합격시켜 폐기했다.** 코드는 저장소에 두지 않았다.

**구현했던 것**: 수확을 세금(공공곡창, 비축 목표 일수까지) / 지대 32%(지배층) / 농가 몫으로 분배. 지배층이 먼저 먹고 장인·상인은 지배층의 곡식을 현물 급료로 받음. 공공곡창을 열면 굶는 사람에게 부족분을 풀어 줌.

**측정 결과** (평형 상태 60년차에 흉년, 이후 5년 관찰, 기아 사망은 농민/장인·상인/지배층):

| 정책 | 흉년 1회(0.55) | 2년 연속 흉년(0.5) |
|---|---|---|
| 비축 0일, 구휼 닫음 | 인구 99.4%, 0 / 807 / 271 | 95.7%, 19 / 1,585 / 532 |
| 비축 60일, 구휼 열림 | 102.4%, 0 / 133 / 45 | 97.1%, 619 / 835 / 283 |
| 비축 180일, 구휼 열림 | 103%, 0 / 0 / 0 | 98.8%, 827 / 288 / 98 |
| 비축 180일, 구휼 닫음 | 99.3%, 0 / 805 / 271 | 90.8%, 1,480 / 1,560 / 527 |

**불합격 사유**
1. **비용 없는 보험**: 비축을 늘리고 구휼을 여는 것이 모든 시나리오에서 이득이고 평년에는 비용이 눈에 띄지 않았다. 세금은 농가 곡식을 공공곡창으로 옮길 뿐이라 총량이 같다. "최대로 쌓고 항상 연다"가 정답이라 레버가 아니다.
2. **쓸모없는 계층**: 장인·상인이 아무것도 생산하지 않아서, 가장 많이 죽는 것이 이들인데도 통치자에게 손해가 없다. 누구를 먹일지가 선택이 되려면 계층마다 통치자에게 다른 가치(생산, 병력, 세수)가 있어야 한다.
3. **설정 불일치**: 시작 구성(농민 60/장인 30/지배 10)과 지대 32%가 맞지 않아 평년에도 장인이 만성적으로 굶었다(150년 평균 누적 기아 사망 농민 약 11,000, 장인·상인 약 6,200, 지배층 약 2,100). 지배층이 굶은 것은 장인 급료를 먼저 내줘서 자기 몫까지 바닥난 모델링 결함이었다.

**교훈**: 분배 구조만으로는 선택이 생기지 않는다. 비축과 곡식에 **경쟁하는 사용처**(군대 보급, 징집으로 빠지는 노동력, 정복 비용)가 있어야 비축에 기회비용이 생기고, 계층에 **서로 다른 가치**가 있어야 누구를 살릴지가 결정이 된다. 그 경쟁 상대가 지금 모델에 없다.
